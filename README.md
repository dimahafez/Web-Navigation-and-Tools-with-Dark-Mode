# Web-Navigation-and-Tools-with-Dark-Mode
## Description
This is a simple web application featuring a main navigation page with the ability to toggle between light and dark modes. It includes various utility tools such as a calculator, currency converter, BMI calculator, and more. The page also tracks the number of visitors using the browser's local storage.

## Features
- Dark mode toggle
- Display current time
- Visitor counter
- Multiple utility buttons for navigation to various tools

## Technologies Used
- HTML
- CSS (Flexbox, Variables, and Responsive Design)
- JavaScript (for functionality like the dark mode toggle, clock, and visitor tracker)
